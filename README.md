# Chess


https://github.com/user-attachments/assets/4b5deca1-d738-4b94-bbc9-ce14e4875b47


This is a simple chess game written in C++, designed for two players. It features basic chess mechanics and allows players to take turns making moves.

# Features
-Two-Player Mode: Play locally with a friend.

-Basic Chess Mechanics: Standard rules for piece movement and captures.

-Simple and Lightweight: No unnecessary complexity—just pure chess.
